Contains code used in the simulation and AFM analysis of "Modelling Adsorption of Partially Animated Dendrimer Monolayers".

afm_filter.py - Filters AFM data to create a monocoloured mask of pixels above a height threshold and a monocoulered remainder.

circleplacement.py - Fits circles to masked AFM data via a procedure described in the paper.

ea_rsa.py - Implements the EA-RSA algorithm described in the paper.

inter_better_cleaned.py - Implements the dPGA-RSA algorithm described in the paper.
